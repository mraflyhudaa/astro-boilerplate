Content layer adalah bagian situs yang paling mudah rusak: frontmatter melenceng, slug tidak lagi
cocok dengan nama file, dan metadata diam-diam berbeda dari halaman. Starter ini memperlakukan id
entri sebagai satu-satunya sumber kebenaran.

## Loadernya

```ts
// src/content.config.ts
const blog = defineCollection({
	loader: glob({ pattern: '**/*.{md,mdx}', base: './src/content/blog' }),
	schema: ({ image }) =>
		z.object({
			title: z.string().min(1).max(120),
			description: z.string().min(1).max(200),
			pubDate: z.coerce.date(),
			heroImage: image().optional(),
			heroImageAlt: z.string().optional(),
			tags: z.array(z.string()).default([]),
			draft: z.boolean().default(false),
			translationKey: z.string().optional(),
		}),
});
```

Loader `glob` menelusuri `src/content/blog` dan menghasilkan id seperti `en/hello-world`. Dari id
itu situs menurunkan:

1. locale, untuk routing dan `hreflang`;
2. slug, untuk URL;
3. path, untuk kartu, RSS, dan endpoint OG.

Karena ketiganya diturunkan, mengganti nama file mengubah URL dan feed sekaligus — tidak ada tautan
basi.

## Validasi yang menggagalkan build

`description` dibatasi 200 karakter agar bisa dipakai ulang sebagai meta description. Tulisan tanpa
`heroImageAlt` menggagalkan build alih-alih merilis gambar hero yang tidak aksesibel:

```ts
.refine((data) => data.heroImage === undefined || data.heroImageAlt !== undefined, {
	message: 'heroImageAlt is required when heroImage is set',
	path: ['heroImageAlt'],
})
```

## Draft

Entri dengan `draft: true` tampil saat development dan disaring dari build produksi oleh
`getBlogPosts()`. Filter yang sama menjaga RSS dan pembuatan OG, sehingga draft tidak bocor lewat
jalur lain.
